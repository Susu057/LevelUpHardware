LEVELUP HARDWARE — SPRINT 1

Bestanden:
- index.html = Home
- about.html = Over ons
- products.html = Producten
- style.css = styling voor alle pagina's
- images/ = door jou aangeleverde afbeeldingen
- STIJLGIDS_EN_MOBIEL_WIREFRAME.md = stijlgids en mobiel wireframe

OPENEN:
1. Pak de ZIP uit.
2. Open Visual Studio Code.
3. Kies File > Open Folder en selecteer de uitgepakte map.
4. Open index.html in de browser (of gebruik Live Server).
5. Controleer ook about.html en products.html.
6. Test op mobiel door de browser smaller te maken.

De nieuwsbriefknop is voorlopig een visueel ontwerp en opent een e-mailconcept.
De Google Maps-kaart toont Breda algemeen omdat het exacte adres nog ontbreekt.
